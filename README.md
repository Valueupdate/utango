# utango（うたんご）

**英単語が、歌になる。**

英単語帳をスマホで撮影するだけで、覚えたい単語が歌詞になった
オリジナルの暗記ソングをAIが自動生成する英単語学習サービスです。

> 🚧 現在 PoC（概念実証）段階です。

---

## コンセプト

英単語帳のページを撮影してアップロードすると、AIが英単語と和訳を読み取り、
暗記に最適化された歌詞を生成し、その歌詞で楽曲を自動生成します。
「自分の覚えたい単語だけが入った、世界に1曲だけの暗記ソング」で
楽しく英単語を覚えられます。

主なターゲットは中学生・高校生。将来的には塾・学校への提供（B2B2C）や
iOS / Android アプリ展開を見据えています。

---

## 処理の流れ

    英単語帳を撮影
        │
        ▼
    [1] 単語抽出   … Gemini Vision で英単語・和訳を読み取り
        │
        ▼
    [2] 歌詞生成   … 反復・エコー構造の暗記歌詞を生成
        │
        ▼
    [3] 楽曲生成   … Lyria 3 Pro で歌詞を固定して楽曲化
        │
        ▼
    [4] 歌詞付き再生 … 歌を聴きながら単語を覚える

---

## 特徴

- **撮るだけ**: スマホで単語帳を撮影するだけ。難しい操作は不要
- **自分専用の曲**: 覚えたい単語そのものが歌詞になったオリジナルソング
- **キー入力不要**: API キーや課金設定はサーバー側で完結（中高生でも使える）
- **暗記に最適化**: 反復・和訳エコーなど記憶に残る歌詞構造を自動生成

## 技術スタック

| レイヤー | 技術 |
|---------|------|
| フロントエンド | Next.js / TypeScript |
| バックエンド | FastAPI (Python) |
| 画像解析・歌詞生成 | Google Gemini |
| 楽曲生成 | Google Lyria 3 Pro（Gemini API） |
| リアルタイム進捗 | Server-Sent Events (SSE) |

姉妹サービス [Slide2Video](https://slide2video.valueupdate.net/) の
技術資産（FastAPI + ジョブ管理 + SSE、Gemini 連携）を流用しています。

## セットアップ

ローカルでの起動手順は [SETUP.md](SETUP.md) を参照してください。

要点だけ記すと、`backend/.env` に運営者の Gemini API キーを設定し、
バックエンド（FastAPI）とフロントエンド（Next.js）をそれぞれ起動します。

楽曲生成に使う Lyria 3 Pro は従量課金モデルのため、
課金が有効な Gemini API キーが必要です。

## 現在の状態

PoC として「撮影 → 単語抽出 → 歌詞生成 → 楽曲生成 → 歌詞付き再生」の
一本道フローを実装済みです。クイズ・SRS（間隔反復）・進捗管理・アカウント・
課金スキーム・モバイルアプリは次フェーズ以降で検討します。

---

## 注意事項

- Lyria 3 は preview 段階のため、モデル仕様が変更される可能性があります
- 楽曲生成 AI の出力物の権利・利用規約は、学習用途の範囲で要確認です
- 撮影画像・生成データは一定時間後にサーバーから自動削除されます
