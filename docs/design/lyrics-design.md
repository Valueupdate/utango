# 暗記歌詞設計（utango P-03 の核心）

## 1. 目的

英単語帳から抽出した「英単語・和訳」のペアを、暗記効果の高い歌詞に変換する。
この歌詞を Lyria 3 Pro に `Lyrics:` で固定して渡し、楽曲化する。
utango の競争力はこの歌詞構造にあるため、Gemini 任せにせず明示的に設計する。

---

## 2. 暗記効果を高める設計原則

### 2.1 反復（Repetition）
同じ単語ペアを最低3回、サビ相当のセクションでは追加で反復する。
記憶の定着には接触回数が効くため、1曲あたりの単語数を絞って反復回数を確保する。

### 2.2 英単語と和訳の隣接（Pairing）
英単語の直後に和訳を置き、意味と音を結びつける。
例: "apple, りんご" のように、英→和の順を基本とする。

### 2.3 和訳エコー（Echo）
和訳をバックコーラス/エコーとして補強する。Lyria の括弧記法を活用する。
例: "apple (りんご), apple (りんご)"
これにより和訳が耳に残りやすく、英単語との対応が強化される。

### 2.4 リトリーバル（思い出す隙）
サビの最後などで「英単語だけ歌い、和訳を一瞬おいてから歌う」構造を入れ、
聴き手が和訳を思い出す隙を作る。能動的想起は記憶定着に効果が高い。
※ PoC では任意。発音明瞭度を優先し、過度に複雑化しない。

### 2.5 発音明瞭度の優先
テンポは速すぎないものを選ぶ（聴き取りやすさ優先）。
1セクションに詰め込む単語数を抑え、各単語がはっきり歌われるようにする。

---

## 3. 1曲あたりの単語数とパラメータ

| 項目 | PoC 初期値 | 備考 |
|------|-----------|------|
| 1曲あたりの単語数 | 6〜10語 | 反復回数を確保できる上限の目安 |
| 各単語の反復回数 | 3回以上 | Verse + Chorus で確保 |
| 曲長 | 約1.5〜2分 | Lyria 3 Pro でプロンプト指定 |
| テンポ | ミドル（聞き取り優先） | 速すぎると発音が崩れる |
| ジャンル | 明るいポップ（初期） | 将来ユーザー選択可に |

※ 単語数が10語を超える場合は複数曲に分割する（PoCでは上限超過分は切り捨て or 警告）。

---

## 4. 歌詞フォーマット（Lyria 3 への入力形式）

Lyria 3 のドキュメントに従い、`Lyrics:` プレフィックスとセクションタグを使う。
括弧 `( )` はエコー/バックコーラスとして解釈される。

### 4.1 テンプレート構造

    [Intro]
    Let's learn some words! (うたんご)

    [Verse 1]
    {word1} ({和訳1}), {word1} ({和訳1})
    {word2} ({和訳2}), {word2} ({和訳2})
    {word3} ({和訳3}), {word3} ({和訳3})

    [Chorus]
    {word1}, {word2}, {word3} (覚えよう)
    {和訳1}, {和訳2}, {和訳3} (もう一回)

    [Verse 2]
    {word4} ({和訳4}), {word4} ({和訳4})
    {word5} ({和訳5}), {word5} ({和訳5})
    {word6} ({和訳6}), {word6} ({和訳6})

    [Chorus]
    {word4}, {word5}, {word6} (覚えよう)
    {和訳4}, {和訳5}, {和訳6} (もう一回)

    [Outro]
    {word1}, {word2}, {word3}, {word4}, {word5}, {word6}

### 4.2 6語の具体例

    [Intro]
    Let's learn some words! (うたんご)

    [Verse 1]
    apple (りんご), apple (りんご)
    ocean (海), ocean (海)
    bright (明るい), bright (明るい)

    [Chorus]
    apple, ocean, bright (覚えよう)
    りんご, 海, 明るい (もう一回)

    [Verse 2]
    travel (旅行する), travel (旅行する)
    gentle (優しい), gentle (優しい)
    forest (森), forest (森)

    [Chorus]
    travel, gentle, forest (覚えよう)
    旅行する, 優しい, 森 (もう一回)

    [Outro]
    apple, ocean, bright, travel, gentle, forest

## 5. Gemini への歌詞生成プロンプト設計

抽出済みの単語ペアを受け取り、§4 のテンプレートに沿った歌詞を生成させる。

### 5.1 プロンプト方針
- 単語ペアの配列を入力として与える
- §4 のテンプレート構造を厳守させる
- 英単語はそのまま、和訳は抽出された日本語を使う（勝手に変えない）
- セクションタグ・括弧エコーを正確に出力させる
- 楽曲指示（テンポ・ジャンル）は歌詞とは別に Lyria プロンプトへ付与

### 5.2 プロンプト雛形（擬似）

    あなたは英単語暗記ソングの作詞家です。
    以下の英単語と和訳のペアから、暗記に最適化された歌詞を作成してください。

    単語ペア:
    {word_pairs}

    ルール:
    - 各単語を Verse で「英単語 (和訳), 英単語 (和訳)」の形で反復する
    - Chorus で英単語をまとめ、続けて和訳をまとめる
    - セクションは [Intro][Verse 1][Chorus][Verse 2][Chorus][Outro] の構成
    - 英単語と和訳は与えられたものを変更しない
    - 歌詞テキストのみを出力する（説明文は不要）

### 5.3 Lyria への最終入力
生成された歌詞を `Lyrics:` プレフィックスで包み、楽曲指示を前置する。

    A bright, upbeat pop song for memorizing English vocabulary.
    Medium tempo, clear pronunciation, cheerful mood.

    Lyrics:
    {生成された歌詞}

## 6. 単語ペア抽出（P-02）の出力フォーマット

歌詞生成の入力となる、Gemini Vision による抽出結果の構造を定義する。

### 6.1 JSON フォーマット

    {
      "word_pairs": [
        { "word": "apple", "meaning": "りんご" },
        { "word": "ocean", "meaning": "海" }
      ]
    }

### 6.2 抽出時の注意
- 発音記号・例文・通し番号など、英単語と和訳以外は除外する
- 和訳が複数ある場合は代表的な1つに絞る（PoC）
- 画像が不鮮明で読み取れない語はスキップし、抽出できた語のみ返す
- 抽出語数が多い場合は §3 の単語数上限に従い先頭から採用する

---

## 7. PoC での簡略化と将来拡張

### 7.1 PoC での簡略化
- ジャンル・テンポは固定（明るいポップ・ミドルテンポ）
- 1曲・単語数上限固定（複数曲分割は将来）
- リトリーバル構造（§2.4）は任意、まずは反復+エコーを優先

### 7.2 将来拡張
- ジャンル選択（ポップ/ラップ/バラード等）をユーザーに開放
- 単語数に応じた自動複数曲化・アルバム化
- 和訳の品詞・例文を歌詞に織り込むモード
- 難易度別テンポ調整（初学者は遅く）
